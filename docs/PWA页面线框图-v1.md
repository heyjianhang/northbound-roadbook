# 北行路书 PWA：ASCII 页面方案 v1

> 实施更新（2026-09-09）：现已开始并完成 v0.2.0 的 Web/PWA 源码落地；下文保留当时规划过程。当前功能、验证边界和自有服务器交付以项目 README.md 与 docs/部署说明.md 为准。
日期：2026-09-09。全部为待实现设计；图中内容和状态是交互示例。本文件优先于归档里的必去点、起终点锁定与营地安排。

## 交互规则

- 所有地点平级，不分必去、计划去或可选；编号仅表示访问顺序。敖鲁古雅也可删除。
- 每天是一个有序地点列表，第一个地点作为算路起点，最后一个作为终点；首尾和中间地点都能编辑、删除、移动。
- 添加、删除、调整顺序或修改坐标后，按新顺序调用高德重算受影响路段。重算不自动更改用户排列顺序。
- 删除仅移除当天的这次停靠；同一地点在其他日期的记录保持独立。删除即时生效并提供撤销，列表与地图同步更新。
- 新增地点默认追加当天末尾，也可指定插入位置；允许同一地点被安排多次，便于往返。
- 当前行程项的修改默认只影响这一项；移动到另一日期时，两天都重算。已有源码的共用地点和固定首尾规则需在实现时迁移。
- 0 个点显示添加入口；1 个点只显示位置和导航入口，不显示驾车里程；2 个及以上地点才计算路线。
- 离线可以编辑、保存地点；重算排队等待联网。路线失效后隐藏不匹配的旧路线与汇总，不把旧里程显示成新结果。只接受与当前列表一致的算路结果，避免旧请求覆盖新操作。
- 原生 App、装备清单、营地筛选、充电规划和多人协同编辑不属于这版线框图。安装、离线保存和 JSON 导入导出放入设置。

## 页面关系

```text
路书 <------------------------> 地图
 |                                |
 +--> 地点详情 --> 编辑地点        +--> 选中地点
 |                                |      |
 +--> 添加地点 <------------------+      +--> 详情 / 导航 / 移除
 |      +--> 搜索 / 地图 / 手动
 |      +--> 填写资料 --> 加入行程
 +--> 调整顺序
 +--> 设置 --> 安装提示 / 离线保存 / 导入导出
```

共 2 个主页面、5 个子页面，另有安装和导入预览弹窗。

## 1. 路书首页

默认进入今天对应的日期；旅行尚未开始时展示首日，用户切换后保留选择。顶部日期可横向滑动。

```text
+----------------------------------------------+
| 北行路书                            [设置]   |
| 10/1  10/2  [10/3]  10/4  10/5  10/6         |
+----------------------------------------------+
| 10月3日 / 第3天                              |
| 3个地点  |  驾车里程、时间显示在这里         |
| 路线已更新                     [重新规划]    |
|                                              |
| 01  根河市区                       [详情]    |
|     停留 30 分钟                             |
|     到下一站：驾车时间                       |
|                      [编辑] [移除]           |
+----------------------------------------------+
| 02  敖鲁古雅使鹿部落               [详情]    |
|     森林栈道、驯鹿  |  停留 90 分钟          |
|     到下一站：驾车时间                       |
|                      [编辑] [移除]           |
+----------------------------------------------+
| 03  莫尔道嘎国家森林公园           [详情]    |
|     森林景观  |  停留 120 分钟               |
|                      [编辑] [移除]           |
|                                              |
| [+ 添加地点]                  [调整顺序]     |
+----------------------------------------------+
| 已移除一个地点                     [撤销]    |
+----------------------------------------------+
|              [路书]       地图               |
+----------------------------------------------+
```

新增、编辑或删除后立即更新列表；“路线已更新”替换为实际算路状态。完成状态下显示真实里程和驾驶时间，本图不填模拟里程。首页不按景点的重要性锁定任何按钮。

## 2. 地图页

与路书共用同一天和同一份地点列表；上方切日，下方卡片随点选变化。

```text
+----------------------------------------------+
| 路线地图                    [+ 添加地点]     |
| 10/1  10/2  [10/3]  10/4  10/5  10/6         |
+----------------------------------------------+
|                                              |
|      (1) 根河市区                            |
|        \                                     |
|         \                                    |
|          (2) 敖鲁古雅                        |
|            \                                 |
|             +----------(3) 森林公园          |
|                                              |
|                               [放大 +]       |
|                               [缩小 -]       |
|                               [看全程]       |
|        地图和线路仅为排版示意                |
+----------------------------------------------+
| 02  敖鲁古雅使鹿部落                         |
| 停留 90 分钟                                 |
| [地点详情]    [去这里]    [移除]             |
+----------------------------------------------+
| 当天路线：3个地点                            |
| 里程 / 驾驶时间               [重新规划]     |
+----------------------------------------------+
|               路书       [地图]              |
+----------------------------------------------+
```

地图显示真实高德道路路径；点标记打开下方卡片，“去这里”进入外部地图导航，失败时可复制地点信息。进入此页时恢复所选日期，不默默切换回第一天。离线或地图失败时仍显示地点列表与入口。

```text
| +--------------------------------------+     |

| 10月3日 / 第2站  |  停留 90 分钟             |
|                                              |
| 看什么                                       |
| 森林栈道、驯鹿                               |

|                                              |
```

## 4. 添加地点页

### 4A. 搜索模式

```text
+----------------------------------------------+
| [< 返回]           添加地点                  |
| 加入日期：[10月3日 v]                        |
+----------------------------------------------+
| [搜索地点]                地图选点           |
|                                              |
| 区域：[根河                       ]          |
| 名称：[根河源                     ]          |
| [搜索]                                       |
+----------------------------------------------+
| 搜索结果                                     |
|                                              |
| 根河源国家湿地公园                           |
| 区域 / 地址                                  |
|                                  [选择]      |
|                                              |
| 没有找到想要的位置？                         |
| [地图选点]                  [手动添加]       |
+----------------------------------------------+
```

选择结果后进入第 5 页确认名称、停留时间和插入位置，保存才加入路书。搜索为空显示“没有找到，试试换个词或地图选点”；失败显示“搜索失败 / 重试”。离线时保留手动添加入口。

### 4B. 地图选点模式

```text
+----------------------------------------------+
| [< 返回]           添加地点                  |
| 加入日期：[10月3日 v]                        |
+----------------------------------------------+
|  搜索地点                [地图选点]          |
|                                              |
|        点击地图选一个位置                    |
|                                              |
|     ~~~~~          +--------+                |
|       ~~~~         |        |                |
|          ~~~~      |   *    |                |
|             ~~~~   |        |                |
|                    +--------+                |
|                                              |
| 选中位置：经度、纬度                         |
| 名称可在下一步填写                           |
```

“使用这个位置”进入第 5 页。未选点时按钮不可用；地图不可用时可以改为手动输入坐标。选点只表示该位置要加入路书。

## 5. 新增 / 编辑地点页

两种操作共用一张表单。新增显示“加入行程”，编辑显示“保存修改”。

```text
+----------------------------------------------+
| [取消]             编辑地点       [保存]     |
+----------------------------------------------+
| 地点名称                                     |
| [敖鲁古雅使鹿部落                  ]         |
|                                              |
| 所属日期                                     |
| [10月3日                         v]          |
|                                              |
| 排列位置                                     |
| [根河市区之后                    v]          |
|                                              |
| 地点位置                                     |
| [查看 / 修改地图位置               ]         |
| [手动填写经纬度                    ]         |
|                                              |
| 计划停留                                     |
| [90          ] 分钟                          |
|                                              |
| 我的备注                                     |
| [想多留一点时间拍照。              ]         |
| [                                 ]          |
|                                              |

| [标题] [网址]                       [x]      |
```

新增默认放在当天末尾，也可选择某个地点之前 / 之后。手动添加复用该表单；坐标可暂缺，但显示“位置待补，无法算路”。有未保存修改时离开，提供“继续编辑 / 放弃修改”，不静默丢弃输入。

## 6. 调整顺序页

拖动全部地点，包括当前第一站和最后一站。上下按钮方便单手操作和无法拖动时使用。

```text
+----------------------------------------------+
| [取消]             调整顺序       [完成]     |
| 10月3日                                      |
+----------------------------------------------+
| 按你想去的先后顺序排列                       |
|                                              |
| ::  01 根河市区               [上] [下]      |
+----------------------------------------------+
| ::  02 敖鲁古雅使鹿部落       [上] [下]      |
+----------------------------------------------+
| ::  03 莫尔道嘎森林公园       [上] [下]      |
|                                              |
| 第一项 = 当天路线起点                        |
| 最后一项 = 当天路线终点                      |
|                                              |
| 所有地点都可以移动                           |
+----------------------------------------------+
| [保存顺序并重新规划]                         |
+----------------------------------------------+
```

“完成”与底部按钮提交同一份顺序；取消恢复进入时的列表。高德按该顺序计算驾车路线，不自动重新排序。

## 7. 设置与离线保存页

从首页进入，集中放安装、保存和备份，避免增加一个装备或账号主入口。

```text
+----------------------------------------------+
| [< 返回]               设置                  |
+----------------------------------------------+
| 安装                                         |
| [添加到手机主屏幕                 >]         |
|                                              |
| 离线路书                                     |
| 六天路书 / 最近保存时间                      |
| [保存最新路书到本机                ]         |
| 可离线：日程、地点、备注、攻略要点           |
| 联网用：高德地图、重算、外部攻略             |
|                                              |
| 数据备份                                     |
| [导出路书 JSON                     ]         |
| [导入路书 JSON                     ]         |
|                                              |
| 使用说明                                     |
| 手机和电脑分别保存本机编辑                   |
| 跨设备可通过导出、导入传递                   |
|                                              |
| 版本                                         |
| 有新版本时显示：[更新并重新打开]             |
+----------------------------------------------+
```

离线保存显示“未保存 / 正在保存 / 已保存 / 保存失败”，路书变动后提示更新保存；下载完成才显示成功。安装状态按设备能力显示，不承诺所有安卓设备都有同一种安装结果。本机保存不标成服务器同步。

系统选择文件后显示预览；格式校验失败时保留现有路书，展示错误与重新选择入口。

```text
+----------------------------------------------+
| 导入路书                             [x]     |
+----------------------------------------------+
| 文件：北行路书.json                          |
| 日期：2026/10/1 - 2026/10/6                  |
| 识别到：6天 / 地点数量                       |
|                                              |
| 导入后替换本机当前路书                       |
| 替换前自动保留一份当前备份                   |
|                                              |
| [取消]                    [导入并替换]       |
+----------------------------------------------+
```

兼容旧版数据时移除必去级别和首尾锁定；按原顺序保留地点，旧版关闭的可选点不重新强行加入当天路线。地点库中的未安排资料仍可保留供再次添加。

## 8. 删除与重算的关键状态

这些是首页 / 地图内的状态，不增加独立页面。

```text
+----------------------------------------------+
| 删除后                                       |
| 已移除：敖鲁古雅               [撤销]        |
| 正在按剩余地点重新规划...                    |
+----------------------------------------------+
| 完成                                         |
| 路线已更新                                   |
| 显示当前地点顺序对应的里程与时间             |
+----------------------------------------------+
| 失败                                         |
| 本次修改已保存，路线暂未更新                 |
| [重试规划]                                   |
+----------------------------------------------+
| 离线                                         |
| 地点已保存，联网后重新规划                   |
| 地图不可用时仍可查看路书                     |
+----------------------------------------------+
```

```text
+----------------------------------------------+
| 当天没有地点                                 |
| [+ 添加第一个地点]                           |
+----------------------------------------------+
| 当天只有1个地点                              |
| 01  莫尔道嘎国家森林公园                     |
| [详情]   [去这里]   [移除]                   |
| 再添加一个地点即可规划路线                   |
| [+ 添加地点]                                 |
+----------------------------------------------+
```

删除最后一个或第一个地点也使用同样规则。撤销恢复删除项及原顺序，并更新地图。重算失败不能显示成成功；不完整路段不得生成看似完整的全天汇总。

同一套页面在宽屏使用双栏，左侧编辑路书、右侧看地图；详情与表单使用侧栏，手机则使用上面展示的整页。

```text
+------------------------------------------------------------------------+
| 北行路书                 10/1 10/2 [10/3] 10/4 10/5 10/6       [设置] |
+-------------------------------+----------------------------------------+
| 10月3日                       |                                        |
| [+ 添加地点] [调整顺序]        |             高德地图                   |
|                               |                                        |
| 01 根河市区   [编辑] [移除]    |    (1)------(2)                        |
| 02 敖鲁古雅   [编辑] [移除]    |                \\                       |
| 03 森林公园   [编辑] [移除]    |                 +------(3)             |
|                               |                                        |
| 路线状态 / [重新规划]          |     选中地点 > 详情 / 导航 / 移除       |
+-------------------------------+----------------------------------------+
```

## 开发时需特别核对

- 来源代码仍有 priority、anchor、required、可选开关和首尾不能移动等限制；不能只改界面文字。
- 迁移需要保留原来实际启用的行程顺序及用户备注，所有保留的行程项转为平级；不能因旧版必去状态使删除失效。
- 使用地点标识、坐标与顺序核对路线结果；变化后重算，避免相反方向或旧请求的记录误用。
- 本稿未实现页面、迁移、离线能力、安装与导航，也未进行浏览器运行验收。
