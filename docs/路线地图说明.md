# 路线地图

- 路线页在一个视口内铺满地图，底部为日期浮条和应用导航，移除标题及下方地点列表；支持全程、当天、拖动、双指缩放、双击、滚轮、加减按钮、地点卡片和按需定位。选中日期用对应颜色加粗。
- 地点卡片可打开已收录的小红书帖子列表或高德导航。城市/镇区中心仅用于地图显示，不改变原有高德找地点行为。
- 地图使用 [Leaflet 1.9.4](https://leafletjs.com/reference.html) 和 [OpenStreetMap 底图](https://operations.osmfoundation.org/policies/tiles/)，无高德 JS Key。底图按当前视口联网加载，未加入 Service Worker 缓存或批量下载。
- 道路数据来自 [OSRM Route API](https://project-osrm.org/docs/v5.24.0/api/)，2026-09-09 生成并保存为静态文件 `data/map-routes.json`。不是实时交通或高德规划结果，不保证选择卡线、边境道路或当季可通行道路；实际导航仍交给高德。
- 路书原始坐标为 GCJ-02；生成时转换至 WGS84，与 OSM 和浏览器定位坐标对齐。海拉尔、莫尔道嘎镇、黑山头的区镇中心另存 `data/map-centers.json`，附高德来源链接。
- 六天分别约 1104、284、162、286、178、1103 km，仅用于轨迹检查，不替换路书原来的参考里程。景区坐标至可通行路网有偏差，最大约 723 米；此图不承诺入口或停车场精确位置。
- “我的位置”点击后才请求浏览器位置权限。在路线页停留期间更新蓝点和精度圈，离开时停止监听；不存储定位，不向路由服务传送当前位置。居中后底图服务会收到相应视口的瓦片请求。HTTPS 或 localhost 可用；拒绝、失败或超时会提示重试。

维护路线：修改地点后运行 `node scripts/build-map-routes.mjs`，检查路线和吸附偏差，再运行常规生产构建。普通构建直接读取保存的轨迹，不依赖路由服务在线。

新增地图依赖时，现有锁文件中 `@jridgewell/trace-mapping@^0.3.38` 无法从 npm 解析。因此在临时目录安装指定 Leaflet 版本，再合并这三个新增包的锁定元数据及 integrity，保持原依赖不变。`npm ls leaflet @types/leaflet` 已确认版本；未宣称全量干净安装通过。
