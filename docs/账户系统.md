# 账户系统

本文面向北行路书的部署管理员和后续开发者，用于配置独立管理员、邀请旅行成员、恢复账号及维护账户数据。

## 使用方式

1. 在 `.env.local` 中设置 `ADMIN_USERNAME`、`ADMIN_PASSWORD`，可选设置 `ADMIN_NAME`。账号为 3–32 位字母、数字、点、下划线或短横线，密码为 10–128 个字符。系统不提供默认密码；未配置密码时禁用管理账户。
2. 使用 `npm run dev` 启动开发环境，或执行 `npm run build`、`npm start` 启动生产服务。管理员使用配置中的账号密码登录，进入独立的“成员管理”页面。
3. 管理员为自己和旅伴分别生成邀请链接。每个链接在 72 小时内可注册一个普通成员，对方自行设置登录账号、密码、名字及可选头像。管理员账号须与所有成员账号不同。
4. 日常使用时，退出管理账号，使用各自的普通成员账号登录。登录成功或接受邀请注册后直接进入“每日路书”，保留链接中选中的日期；“账户”页可修改本人的名字、头像和密码。已登录时刷新页面或打开分享链接保留所选页面。管理员仅负责邀请、撤销邀请、停用／启用成员以及生成密码重置链接，不进入路书，也不作为旅行成员。
5. 成员忘记密码时，由管理员生成 1 小时有效的重置链接。只有对方使用链接提交新密码后，密码才变化，旧登录同时失效。同一人的新重置链接会使旧链接失效。
6. 管理员修改资料或忘记密码时，直接修改环境配置并重启服务；生产使用 `npm start`，开发使用 `npm run dev`。修改管理员账号或密码后，旧管理会话自动失效；成员资料、密码和会话不受影响。配置未变的正常重启保留有效管理会话。

```dotenv
ADMIN_USERNAME=admin
ADMIN_PASSWORD=请替换为你生成的强密码
ADMIN_NAME=系统管理员
```

服务器进程环境变量优先于 `.env.local`；通过 Docker 或进程管理器注入配置时，需要更新注入值并重建容器或重启进程。上述密码仅为格式示意，不可用于实际部署。

邀请和重置链接仅在生成时显示，不在列表中保存明文。无需短信、邮箱或第三方登录。邀请备注用于管理员识别，不限制对方填写的名字。

## 存储与部署

运行环境为 Node.js 22.13+，使用内置 SQLite 和 crypto，无新增运行时包。

| 配置 | 默认值 | 用途 |
|---|---|---|
| `ADMIN_USERNAME` | 无 | 独立管理账号，不能与成员重名 |
| `ADMIN_PASSWORD` | 无 | 管理员密码；留空禁用管理员并撤销管理会话 |
| `ADMIN_NAME` | `系统管理员` | 管理页面显示名称 |
| `ACCOUNTS_DB_PATH` | `.runtime/accounts.sqlite` | 账户、头像、邀请、重置令牌、会话及限流记录 |
| `PUBLIC_ORIGIN` | 本地请求的 origin | 对外部署时设置为实际 HTTPS 站点 origin，例如 `https://trip.example.com` |

数据库路径相对于服务的工作目录。将其放在持久化磁盘上，禁止放到 `public/` 或 `dist/`。`.runtime/`、数据库和 WAL 文件不进入 Git 或构建上下文；开发服务器拒绝下载数据库文件。

对外部署须使用 HTTPS；生产会话 Cookie 总是携带 Secure，此外还包含 HttpOnly、SameSite=Lax 和 30 天有效期。反向代理应原样保留浏览器 Origin，不应把账户 API 缓存或暴露跨域 CORS。设置 `PUBLIC_ORIGIN` 后，复制的邀请链接须从该正式域名页面生成。

Docker 镜像保留 Node 服务及高德、账户相关脚本。挂载 `/app/.runtime` 持久化目录，注入 `ADMIN_USERNAME`、`ADMIN_PASSWORD`、`ADMIN_NAME`、`PUBLIC_ORIGIN` 和高德环境变量。普通浏览器访问本机 127.0.0.1 只适用于本机预览，不能把该地址发给另一台手机注册；两人使用时应部署到共同可访问的 HTTPS 域名。

备份时先停止服务，再完整备份 `.runtime/`；恢复到相同配置路径后启动。不要只复制仍在写入中的 SQLite 主文件而遗漏 WAL。配置未变时，服务器重启不会清除账号、有效邀请或会话。

## 登录与权限边界

管理员配置仅由 Node 服务读取，不使用 `VITE_` 或 `NEXT_PUBLIC_` 前缀，也不返回前端。管理员在数据库中使用固定身份保存密码派生值和会话，环境配置是其唯一维护来源；资料、密码和重置接口禁止修改管理员。若升级自初始化链接版本，原管理员账号保留原资料和密码并转为普通成员，旧会话撤销；初始化链接作废。若新管理账号与旧账号重名，服务返回配置错误，须改用独立的 `ADMIN_USERNAME`，不会覆盖原账号。

密码使用独立随机盐及 scrypt（N=32768、r=8、p=3）派生后保存。随机会话及链接令牌在数据库中仅保存 SHA-256 摘要。写接口检查 Origin、JSON Content-Type 并限流；邀请消费和用户创建在同一个事务中进行。

服务端在每个受保护接口校验会话和角色；高德配置和代理只允许普通成员访问，管理接口只允许管理员访问。停用、重置密码会撤销旧会话；个人修改密码会撤销其他设备并轮换当前会话。客户端切回前台、网络恢复及前台每分钟重新检查登录状态；敏感请求无需等待轮询即可拒绝失效会话。

头像在浏览器裁切压缩为 160×160 JPEG 后上传，服务端检查图片类型、文件头和体积，不接受 SVG 或任意远程头像 URL。注册和修改资料只能写名字和头像，角色等字段由服务端决定。

本阶段实现的是账户层：个人资料、会话、邀请、成员管理以及高德配置／代理接口受服务器鉴权保护。原有六天路书、配图和帖子仍是打包的固定展示数据，登录门面不应被视为这些静态内容的保密措施；后续共享编辑须迁移到鉴权的数据 API。不能在固定 JSON、公开资源或前端代码里加入私人聊天或用户秘密。

账户 API 不进入 Service Worker 缓存，不将密码、会话令牌或用户资料写到 localStorage。应用资源仍可缓存，但本版打开页面需要在线验证账户；尚未实现离线身份验证、共享聊天或行程数据同步。

## 接口

统一前缀 `/api/accounts/`。除 `session`、`members`、`companions` 使用 GET 外，其余均为 POST JSON。所有响应 `Cache-Control: no-store`。

| 接口 | 权限 | 作用 |
|---|---|---|
| `session` | 公开 | `adminConfigured` 及当前用户，不包含密码或令牌 |
| `companions` | 普通成员 | 在用旅伴的 ID、名字、头像，用于聊天发言者展示 |
| `link` | 持有一次性链接 | 校验链接类型和有效期 |
| `register` | 有效邀请 | 注册普通成员 |
| `login` / `reset` | 账号密码／重置令牌 | 登录／重置密码 |
| `logout` | 已登录 | 退出当前身份 |
| `profile` / `password` | 普通成员 | 修改本人资料／修改本人密码 |
| `members` | 管理员 | 普通成员列表和最近邀请摘要（不包含管理账号） |
| `invites` / `invites/revoke` | 管理员 | 创建／撤销邀请 |
| `members/status` / `members/reset` | 管理员 | 停用或启用普通成员／生成重置链接 |

## 验证

运行 `npm run typecheck`、`npm run lint`、`npm test` 和 `npm run build`。`tests/accounts.test.mjs` 覆盖环境管理员同步、配置变化后管理会话撤销、成员不受影响、旧管理员迁移、管理与旅行权限分离、邀请消费并发、角色越权、失效会话、密码轮换、重置、头像验证、跨站请求、限流、数据库重开及生产入口。

`tests/accounts.integration.jsx` 验证管理员只进入管理页、成员返回原路书地址、退出后回到登录，以及旧初始化链接的退场提示。真机 PWA 行为需要单独验证。
