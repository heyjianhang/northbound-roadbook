# 高德版部署说明

当前只提供本地预览，未发布远程服务器。

1. 解压 `release/northbound-roadbook-0.3.3-amap.zip`，保留 `dist/client/` 与 `scripts/` 目录结构。
2. 将 `.env.example` 复制为 `.env.local`，填写高德 Web端 Key、安全密钥。凭据不随发行包提供。
3. 在 Node 22.13+ 环境运行 `node scripts/serve.mjs`。
4. 对外部署使用 HTTPS 反向代理；按需设置环境变量 HOST=0.0.0.0 与 PORT，配置高德控制台域名。
5. 高德密钥代理必须与页面同源；仅上传 HTML 文件到静态托管无法提供代理。

路线和帖子仍为固定数据，没有数据库。发布更新时替换 `dist/client`，网页检测到更新后自动载入；高德 JS 及地图瓦片不加入本地缓存。安全配置、定位边界与来源见 `高德地图配置.md`。
