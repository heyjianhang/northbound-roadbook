# 高德地图运行方式

当前使用高德 JS API 2.0 底图，保留六天道路参考轨迹、日期颜色和定位。位置来自浏览器持续定位，转换到高德坐标后显示蓝点与精度圈；首次点击才申请权限，离开路线页停止监听，不存储或上传历史轨迹。高德 API 不会自动绕过浏览器的定位权限或设备定位能力。

## 本地运行

1. 在项目根目录 `.env.local` 设置 `AMAP_JS_KEY`、`AMAP_SECURITY_JS_CODE`，分别对应高德 Web端（JS API）Key 与安全密钥。
2. `npm run build` 后 `npm start`。服务端自动读取 `.env.local`，修改配置后重启服务。
3. 高德控制台使用 Web端 Key；部署时配置实际域名，HTTPS 用于浏览器定位。

安全密钥只由 Node 服务端读取，通过限定路径的 `/_AMapService/` 代理转发。`/api/amap-config` 只返回 JS 公共 Key，接口不缓存；`.env.local` 不进入发行包。

## 部署

原纯静态托管需增加同源配置接口与高德代理；当前的 `scripts/serve.mjs` 已提供这两个功能。可使用 `release/northbound-roadbook-0.3.3-amap.zip`：解压后复制 `.env.example` 为 `.env.local` 填写自己的凭据，运行 `node scripts/serve.mjs`（Node 22.13+）。设置 `HOST=0.0.0.0` 供反向代理访问，外部使用 HTTPS。

不能只上传网页文件并期待安全代理生效；也不要把安全密钥写入公开 JS。参考：[高德安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)、[高德定位说明](https://lbs.amap.com/api/javascript-api-v2/guide/services/geolocation)。

## 返回与标记

地图卡片进入帖子时附上来源与地图日期；返回按钮恢复原地图日期、全程/当天、中心、缩放和选中地点。内存中的视野只用于当前页面会话；刷新或直接打开帖子时仍可回到地图，不能恢复刷新前的相机状态。普通路书入口返回路书。

普通地点的圆点改为 CSS 圆形，以几何中心定位，不再使用字体字符；高德标记锚点为 center、偏移为 0。城市与镇区仍是参考坐标，不等同于景区入口。

底图已经换为高德；道路轨迹仍是 2026-09-09 保存的 OSRM 参考数据，转换为 GCJ-02 绘制。并未声称轨迹是实时高德在线规划或当前路况；导航按钮打开高德正式导航。

## 手机唤起高德 App

面向维护导航入口的开发者：每日路书、路线地图卡片和地点详情中的高德链接统一通过 `lib/amap-navigation.ts` 生成。iPhone 使用 `iosamap://`，安卓使用 `androidamap://`，由当前窗口的普通链接直接唤起；桌面保留高德网页入口。

有有效坐标时使用 `navi`，传入真实纬度、经度和地点名；路书坐标已经是 GCJ-02，设置 `dev=0`，避免重复偏移。没有具体坐标的城区或镇区使用 `poi` 搜索，关键词包含呼伦贝尔与地点名；iPhone 使用 `name`，安卓使用 `keywords`，不将地图参考中心当作导航目的地。

手机需要已安装高德，浏览器或系统可能弹出打开 App 的确认。这里不预先打开网页窗口，也不使用定时器自动转去网页。App 唤起及回跳仍需在实际设备上验收。

参数依据：[Android 导航](https://lbs.amap.com/api/amap-mobile/guide/android/navigation)、[iOS 导航](https://lbs.amap.com/api/amap-mobile/guide/ios/navi)、[Android 搜索](https://lbs.amap.com/api/amap-mobile/guide/android/search)、[iOS 搜索](https://lbs.amap.com/api/amap-mobile/guide/ios/search)。
