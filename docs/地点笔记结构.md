# 地点帖子与笔记

本文面向维护路书页面及 Agent 的开发者，用于实现、验证地点资料浏览与共同笔记编辑。

模式：设计并实现。

## 1. 项目现状

| 项目事实 | 已确认内容 | 实现影响 |
|---|---|---|
| UI 根目录 | northbound-roadbook | 沿用当前应用 |
| 框架 | Vinext / Vite，Next App Router 结构，React 19，RSC，npm | 交互位于客户端组件 |
| shadcn | base-nova、Base UI、Lucide | 复用现有组件 |
| 主题与壳层 | app/globals.css、StaticRoadbook、PlaceCover | 保留现有主题、封面和底部导航 |
| 相邻实现 | 地点帖子列表、AI Elements MessageResponse | 保留帖子链接，复用 Markdown 渲染能力 |
| 查询记录 | project_context 的 summary、routes(place)、shell、components(place)；shadcn info --json、docs tabs textarea empty alert button | 官方 registry 为 @shadcn；查询完成 |

## 2. 页面目标

旅伴进入地点页后浏览帖子、阅读共同笔记、编辑并保存 Markdown。主要编辑操作为“保存笔记”，进入路径保持每日路书和路线地图，返回原入口。

## 3. 信息优先级

地点封面 → 帖子/笔记标签 → 对应内容 → 编辑操作与保存状态。

## 4. 组件清单

| 区域 | 组件 | 状态与来源 |
|---|---|---|
| 封面 | {PlaceCover} | 现有业务组件 |
| 切换 | Tabs、TabsList、TabsTrigger、TabsContent | 已安装，components/ui/tabs.tsx |
| 编辑 | FieldGroup、Field、Textarea、Button | 已安装，components/ui |
| 反馈 | Empty、Skeleton、Alert、Spinner | 已安装，components/ui；复用 {Notice} |
| 展示 | {NoteMarkdown}，组合 AI Elements MessageResponse | 复用 Streamdown，静态 Markdown 模式 |

## 5. 结构

```text
{PlaceCover 地点封面}
[TabsList 帖子 | 笔记]
├─ [TabsContent 帖子] 现有帖子链接 …
└─ [TabsContent 笔记]
   ├─ 最近编辑者                     [Button 编辑]
   ├─ {NoteMarkdown}
   └─ 编辑时：[Tabs 编辑 | 预览]
             [Field / Textarea Markdown]
             [Button 取消] *[Button 保存笔记]
```

## 6. 交互

默认展示帖子，标签写入 URL，前进后退可恢复。切换帖子/笔记保留当前页面内草稿。编辑时可预览；保存成功显示 Markdown。笔记标签可见时定期检查更新，窗口重新获得焦点时刷新；编辑中的草稿不会被远端刷新替换。

## 7. 状态

加载使用 Skeleton；没有内容时显示 Empty 和“写笔记”；加载失败提供重试。保存中禁用重复提交，失败保留草稿。版本冲突提示最新版本已变化，提供复制草稿和加载最新笔记，不能强制覆盖。取消编辑返回已保存版本。

## 8. 响应式与可访问性

桌面与手机均采用单列；标签等宽，编辑/预览切换而非压缩成并排编辑器。按钮可换行，长链接与代码可滚动。沿用底部导航安全区留白。标签支持键盘，编辑框有 Label，加载、保存和错误状态有语义提示。

## 9. 数据与接口

本次新增成员接口 GET/POST `/api/agent/notes`，分别读取和保存地点笔记。内容、版本号、最近编辑者和时间保存在服务端 `notes.sqlite`。地点标识必须来自固定路书，同名地点的不同停靠记录归入首次出现的地点 ID。

内置 stdio MCP 提供 `list_place_notes`、`read_place_note`、`write_place_note`、`edit_place_note`。身份由已鉴权的后端注入，不作为模型可修改参数；保存和精确替换必须携带读取时的版本。外部 MCP 的只读规则不变，笔记写操作仅针对本应用的共同笔记。

## 10. 范围

每个地点一份共同 Markdown 文档，所有已登录旅伴可编辑。帖子继续使用已有收录内容。笔记与长期记忆独立，笔记修改不会改变行程或发布外部帖子。

## 11. 验收

验证标签与 URL、Markdown、安全链接、手动保存、跨成员读取、重复地点共享、冲突保护、异常草稿保留、Agent 真实 MCP 编辑，以及重启后持久化。
