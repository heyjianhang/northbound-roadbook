### 安装与离线边界

- 支持安装的浏览器根据 Web App Manifest、图标和启动配置呈现安装入口。生产访问使用 HTTPS；安装与离线能力需要分别实现。[MDN 安装说明](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)
- iPhone 可从 Safari 分享菜单添加到主屏幕；支持的系统上启用“作为 Web App 打开”。具体菜单依系统版本变化。[Apple 官方说明](https://support.apple.com/en-gb/guide/iphone/iphea86e5236/ios)
- 安卓的安装结果取决于浏览器、系统和设备服务条件；部分设备只能得到浏览器快捷方式。应以用户实际安卓手机验证，不能承诺所有安卓都相同。
- 离线保存范围限定为应用自身资源、路书资料及明确下载的自有内容；高德地图瓦片与代理接口不纳入通用离线缓存。首版不承诺离线底图、离线重算或离线语音导航。
- 小红书原文通过链接联网打开；自己整理的攻略要点可进入离线路书。安装图标不代表已下载外部攻略。
- 浏览器缓存可能被清除，保留备份和明确的下载状态。[MDN 缓存说明](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Caching)

### 改造工作与验收

1. 在当前工作目录恢复归档源码，保留原归档作为来源；沿用现有依赖与数据迁移约定。
2. 补应用清单、图标和移动端启动配置；生产 Node 静态服务补正确的 Manifest 类型和 Service Worker 更新策略。
3. 补应用资源离线缓存及明确的“保存路书到本机”状态，按实际需要选择本地数据存储；处理缓存更新而不覆盖个人路书。
4. 风景路书在地图未加载或断网时仍能独立打开和切换日期；进入方式、路线概况和自己的攻略要点可读。
5. 部署到用户自有服务器，配置域名与 HTTPS；沿用服务端高德代理。现有 `.openai/hosting.json` 的静态输出声明不代表高德代理会被静态托管自动接管。
6. 真机验收：安卓和 iPhone 的主屏幕入口；有网保存后断网冷启动；日期切换；地图导航与回退；网站升级后用户资料保留；JSON 备份恢复。若增加共享路书，再验收两机获取同一版本和未发布编辑不被覆盖。
